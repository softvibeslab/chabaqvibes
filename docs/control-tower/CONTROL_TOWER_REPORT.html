Modelo de datos

MemberProfile

Representa a cada integrante humano: nombre, rol, proposito, estado, superpoderes, skills, canales, tareas, knowledge y Hermes asociado.

dataset/control-tower/schemas/member-profile.schema.json

HermesAgent

Agente independiente por integrante: mision, prompts, knowledge scopes, grafo, tools, permisos, canales y observabilidad.

dataset/control-tower/schemas/hermes-agent.schema.json

Task

Tarea asignable con owner humano, Hermes de soporte, agency-agents de apoyo, prioridad, estado y links.

GraphArtifact

Salida de Graphify por proyecto o por integrante: JSON, HTML, reporte, conteos y fecha de generacion.

Arize AI Provider Integration

Arize se usara para observabilidad y evaluacion: trazas, evaluadores LLM-as-judge, experimentos y monitoreo de calidad.

Estado actual: las skills de Arize estan instaladas, pero el CLI ax no esta disponible en el PATH. 
ax spaces list
ax ai-integrations list --space CHAMBAQ_SPACE

ax ai-integrations create \
  --name "ChambaQ Gemini" \
  --provider gemini \
  --api-key $GEMINI_API_KEY \
  --function-calling-enabled

Regla: no guardar API keys en el repositorio y no buscar secretos en archivos locales.
